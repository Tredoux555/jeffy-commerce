# JEFFY — THE EXPERIMENT (Minimum Viable Test)

**Surfaced in the admin at `/admin/experiment`.** This file is the canonical source; the admin page renders it as a dashboard.

> The principle: **don't fund a year — fund the cheapest test that can kill the idea.**
> We run Year 1 as a falsifiable experiment in stages, with a hard go/no-go gate before any serious money goes in. If the loop works in one place, we earn the right to spend big. If it doesn't, we found out cheaply.

---

## 0. THE ONE QUESTION THIS ANSWERS

> **Does the loop work in one place?**

Everything below exists to answer that for the least possible money. The loop has four links, and we test them in cost order — cheapest, most likely to fail, first:

1. **Pull** — does the Wish List actually flood the WhatsApp line? (Do people want in?)
2. **Reach** — do the winner stories travel and earn attention we didn't pay for?
3. **Operations** — can one flagship seller run receive → list → sell → deliver → draw → hand-over without it breaking?
4. **Economics** — after landed cost (incl. FX), returns, and the seller's margin, is there a positive contribution per order — or a clear path to one?

If link 1 or 2 fails, we never spend on 3 and 4. That is the whole point.

---

## 1. THE STAGES (spend gates, not a budget you commit up front)

### STAGE 1 — SIGNAL (≈ R15k–R30k · ~4–6 weeks)
*Tests links 1 & 2. No inventory, no hire, almost no risk.*

- Stand up the WhatsApp wish line + missed-call backup (near-free).
- Pre-grant **one small wish** (R1k–R3k) and film it properly. Launch with proof, not a request.
- Run it yourself, or screen a student creator with a paid trial brief (R500–R1,000 each × 2–3 finalists).
- Tiny boost spend (R2k–R5k) on whatever performs organically.

**What success looks like:** the wish line fills up on its own, and at least one piece of content earns real organic reach without heavy spend.

**Kill criterion:** after ~6 weeks, entries are a trickle and the stories get no traction even when boosted → **stop.** The engine doesn't fire. Total spent to learn: ~R15k–R30k.

---

### STAGE 2 — PROVE THE LOOP (≈ R80k–R120k · ~3–4 months)
*Only if Stage 1 fires. Tests links 3 & 4 with one flagship seller.*

- First product shipment — small, the range you already know (**~R50k**, mostly recoverable: unopened stock resells at ~70% wholesale).
- Hire a **student-tier manager** (~R8k/month × 3–4 = R25k–R35k) to run the line and content.
- Stand up **one flagship seller** (most likely Johannesburg) and run the full loop end-to-end.
- Grant 2–3 monthly wishes (R5k–R10k). Modest boosts (R10k–R15k).

**What success looks like:** the loop runs clean for a full cycle, real sales happen, the flagship seller delivers well, and the **unit economics clear after returns and FX** — even if small.

**Kill criterion:** the loop keeps breaking, the seller flakes, or contribution margin stays negative after returns/FX with no path to positive → **stop or rework.** You've spent ~R100k–R130k, of which ~R35k–R40k of inventory comes back.

---

### THE GATE — GO / NO-GO (before the big money)

Do **not** commit the full Scenario-B campaign (mid-level manager, real boost spend, reorders, more sellers — the **R200k–R420k** envelope) until Stage 2 passes on evidence. Set your own numbers; sensible defaults:

| Gate metric | Default target (set your own) |
| --- | --- |
| Wish-line entries (one metro) | ≥ 50 / week, sustained for a month |
| Organic reach | ≥ 1 piece hitting 50k+ views without heavy spend |
| Flagship loop | 1 full cycle clean: receive → sell → deliver → draw → hand-over |
| Sell-through | ≥ 50% of a batch sold within ~8 weeks |
| Unit economics | Positive contribution per order after landed cost (FX), returns, seller margin |
| Returns | Rate manageable; the hold-back / reserve mechanic works in practice |

**Pass = earn the right to the R200k+ spend.** Miss = you learned it for ~R100k–R150k instead of R300k+.

## 2. WHAT YOU ACTUALLY RISK

| | Spend | Truly unrecoverable if it fails |
| --- | --- | --- |
| Stage 1 (signal) | R15k–R30k | ~all of it (but tiny) |
| Stage 2 (prove loop) | R80k–R120k | ~R60k–R90k (inventory ~R35k–R40k recoverable) |
| **To fully answer the question** | **~R100k–R150k** | **~R75k–R120k** |
| Full Year-1 campaign | R200k–R420k | **only spent AFTER the gate passes** |

Already spent and **not** part of this decision: the platform build, company registration, import licence. Don't let sunk cost weigh the go-forward call.

The bigger cost is your **focus** — a few months of it for Stage 1+2 vs. a full year for the whole campaign. Stage-gating protects that too.

---

## 3. ORDER OF OPERATIONS (do these in sequence)

1. **[STAGE 1]** Register the WhatsApp Business line + missed-call backup.
2. **[STAGE 1]** Pre-grant + film one small hero wish. Launch with proof.
3. **[STAGE 1]** Post to FB + TikTok + Reels + Shorts. Tiny boosts on winners only.
4. **[STAGE 1 — CHECK]** Did the line flood and a story travel? If no → stop. If yes → continue.
5. **[STAGE 2]** Place the small first shipment. Hire a student-tier manager.
6. **[STAGE 2]** Stand up the flagship Joburg seller. Run the full loop, monthly draws.
7. **[STAGE 2]** Track contribution margin after returns + FX on every order.
8. **[GATE]** Hit the targets in §1? If yes → commit the full campaign (`/admin/campaign`). If no → rework or stop.

---

## 4. WHY THIS IS THE RIGHT WAY TO BET

The odds on the full vision are modest (~15% to the big version; ~35–45% to a real-but-smaller business). But those aren't fixed — they're a **starting position you move.** The single biggest unknown is "does the loop work?" Stage-gating answers exactly that, for the price of a cheap car instead of an expensive one. The downside is bounded; the information is worth the same either way.

> Fund the experiment, not the dream. Let the experiment earn the dream its money.
