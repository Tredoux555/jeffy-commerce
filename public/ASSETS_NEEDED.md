# Required Assets for Production

## PWA Icons (public/icons/)
Create these icon sizes for the PWA manifest:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

Use the Jeffy logo with orange (#ff6b35) background.

## Other Assets (public/)
- og-image.png (1200x630) - Social sharing image
- apple-touch-icon.png (180x180) - iOS home screen icon
- favicon.ico - Browser tab icon

## Notification Sound (public/sounds/)
- notification.mp3 - Short chime for admin notifications

## Quick Tool
Use https://realfavicongenerator.net/ to generate all icons from a single high-res logo.
